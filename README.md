# 🧮 Python Calculator

A simple command-line calculator built using Python.

## ✨ Features

* Addition
* Subtraction
* Multiplication
* Division
* Division-by-zero handling
* Easy-to-use menu

## 🛠️ Technologies Used

* Python 3

## 📂 Project Structure

```text
Calculator/
├── calculator.py
└── README.md
```

## ▶️ How to Run

Make sure Python is installed.

Open the terminal in the project folder and run:

```bash
python calculator.py
```
